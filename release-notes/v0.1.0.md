# ReplayDrill v0.1.0

最初のリリースです。A Realm Recorded のリプレイを再生しながら、ギミックの回避を練習できます。

## 機能

- リプレイの中の好きなプレイヤーキャラを、自分で動かせます（`/rdrill` で窓を開き、キャラを選んで「練習を始める」）。
  - ゲームのキー設定で移動に割り当てたキー、マウスの左右ボタン同時押し（前進）、パッドの左スティックで動かせます。前はカメラの向きです。
  - ジャンプもできます（見た目だけで、判定には影響しません）。
  - 一時停止中も動けるので、止めて立ち位置を決めてから再生できます。
  - 選択欄には、日本語のジョブ名とジョブアイコンを表示します。
- 敵の技が発動した瞬間に、動かしているキャラが範囲内にいたかを判定し、「回避」「被弾」を一覧に記録します。被弾すると頭上に技名が出ます。
  - 形（円・ドーナツ・直線・扇・十字）と大きさは、ゲームデータから決めます。
  - 生きているプレイヤー全員に当たった技は「全体」、プレイヤーを中心にした円は「対象者」として、回避率から除きます。
- ノックバック・引き寄せ・強制移動が、動かしているキャラにもかかります。
  - ボス起点・対象者起点のノックバック、デバフが切れたときの吹き飛ばしに対応しています。壁に当たるとそこで止まります。
  - 混沌の風・混沌の逆風のように、正面・背面で距離が変わるデバフに対応しています。
  - 絶妖星乱舞の真空波のように、技のデータに入っていないノックバックにも対応しています。
  - 強制移動の命令デバフが付いていると、「強制移動」になった瞬間のキャラの向きを基準に歩かされます。

## 注意

- 引き寄せと強制移動は、まだ実際のリプレイで確かめていません。
- 塔や頭割りのように、わざと当たるギミックは区別できないため「被弾」になります。
- キャラの位置の書き換えは、リプレイを再生している間だけ行います。
