# ReplayDrill

A Realm Recorded（ARR）でリプレイを再生しながら、ギミックの回避を練習する Dalamud プラグインです。

リプレイの中の好きなプレイヤーキャラを自分で動かし、敵の技が発動した瞬間に、そのキャラが範囲内にいたかを判定します。
予兆はリプレイ自身が表示するので、本番と同じ見た目のまま練習できます。

## 使い方

1. A Realm Recorded でボス戦のリプレイを再生します。
2. `/rdrill` で窓を開き、動かすキャラを選んで「練習を始める」を押します。
3. ゲームのキー設定で移動に割り当てたキー（標準は WASD）、マウスの左右ボタン同時押し（前進）、パッドの左スティックで動かします。前はカメラの向きです。一時停止中も動けるので、止めて立ち位置を決めてから再生できます。
4. 技が発動するたびに、一覧に「回避」「被弾」が記録されます。被弾するとキャラの頭上に技名が出ます。

## 判定について

- 形（円・ドーナツ・直線・扇・十字）と大きさは、ゲームデータ（Action シートの CastType・EffectRange・Omen など）から決めます。
- 生きているプレイヤー全員に当たった技は、全体攻撃として「全体」に分け、回避率に含めません。
- 散開や頭割りのように、プレイヤーを中心にした円は「対象者」に分け、判定しません。
- 塔や頭割りのように、わざと当たるギミックは区別できないため「被弾」になります。

キャラの位置の書き換えは、オフラインで再生しているリプレイの中だけで行います。

## インストール

Dalamud の設定（`/xlsettings`）→「Experimental」→「Custom Plugin Repositories」に次の URL を追加し、プラグイン一覧から `ReplayDrill` をインストールしてください。

```text
https://raw.githubusercontent.com/Rin-0617/RinPlugins/main/pluginmaster.json
```

A Realm Recorded も必要です。
